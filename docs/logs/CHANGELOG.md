## [v2.56 / V14A+V14B] - 2026-08-19
### ✨ 新增功能 (Features)
- **V3 大戶群體集中度觸發條件 (條件 B)**: 依 PRD_LM01_V3風控_大戶觸發條件 v1.1
  + prod_gms.xml (20260819) 實作，參數與細部口徑以 prod_gms 為準。
  - 每階段觸發改為二擇一 (OR)：條件 A (預估 RTP 門檻，現有) 或
    條件 B (大戶集中度 **且** ΔRTP 達該階門檻)；命中不同階段取較嚴。
  - 大戶 = 三同格下注 ≥ 注碼門檻 (prod 預設 3,000)；集中度 = 全部大戶
    合計佔該格 ≥ 門檻 (prod 預設 50%)；四階 ΔRTP 門檻 4.0/2.0/1.5/0.5pp。

    大戶不計入，五關遞減；大戶身分/集中度/N* 由下注時點決定，五關不變。

    停用時不得殘留 delta，違規時儲存被拒。whale 參數全刪 = 停用 (向後相容)。

  窗口的 GGR **低於** `ggr_threshold` → 強制 U_PRT_L1，凌駕四階與大戶條件。
  - `ggr_threshold` 可負/0/正，**0 = 不能虧損** (由盈轉虧即介入)；prod 預設 0。
  - 新增 **GGR 專用窗口** `ggr_window_rounds` (prod 24h ≈ 24,000 局)，與
    `rtp_window_rounds` (48,000 局，V2 換表與 V3 RTP 條件用) 互相獨立。
